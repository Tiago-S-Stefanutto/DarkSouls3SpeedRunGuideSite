# 🔥 Dark Souls 3 Speedrun Guide

Um guia completo e interativo para speedruns de Dark Souls III, projetado para speedrunners de todos os níveis - desde iniciantes até veteranos. O site fornece informações detalhadas sobre categorias, glitches, rotas otimizadas e recordes mundiais.

## 🌟 Features

### 📚 Categorias de Speedrun
- **Any%** - Complete o jogo o mais rápido possível usando qualquer meio
- **Any% Glitchless** - Categoria ideal para iniciantes, sem glitches
- **All Bosses** - Derrote todos os 25 chefes do jogo (incluindo DLCs)
- **All Bosses Glitchless** - A categoria mais desafiadora e completa
- **Any% Restricted** - Any% com restrições específicas
- **Any% CP** - Current Patch com todas as atualizações
- **Extensões especiais** - SL1, No Death, No Hit, Randomizer

### 🐛 Glitches e Bugs
Documentação detalhada dos principais glitches:
- **Ladder Warp** - Teleporte através de escadas
- **Dungeon Skip** - Pule a maior parte da Irithyll Dungeon
- **Pivot Sprinting** - Técnica de movimento para velocidade
- **Frozen Princes** - Bug nos Twin Princes
- **Quit Out** - Reset de posições estratégico
- **Bow Glitch** - Atravesse paredes com arcos
- **Fall Control** - Controle de quedas
- **Menu Storage** - Armazenamento de inputs
- **Animation Cancel** - Cancele animações

### 🗺️ Guias de Rotas
- **Any% Glitchless - Rota Sharp +3** - Guia completo para iniciantes
- **Estratégias de Boss** - Táticas detalhadas para todos os chefes
- **Otimização de Movimento** - Técnicas avançadas de movimento
- **Builds e Equipamentos** - Configurações otimizadas
- **Dicas para Iniciantes** - Fundamentos essenciais
- **Estratégias Avançadas** - Para speedrunners experientes

### 🏆 Recordes Mundiais
Seção dedicada aos recordes com:
- Vídeos incorporados dos recordes
- Estatísticas detalhadas das runs
- Informações sobre os speedrunners
- Histórico de recordes recentes

## 🚀 Como Executar

### Pré-requisitos
- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- Conexão com internet (para Font Awesome e vídeos do YouTube)

### Instalação Local
1. Clone ou faça download do repositório
```bash
git clone [URL-DO-REPOSITÓRIO]
cd dark-souls-3-speedrun-guide
```

2. Abra o arquivo `index.html` em seu navegador
```bash
# No Windows
start index.html

# No macOS  
open index.html

# No Linux
xdg-open index.html
```

### Servidor Local (Recomendado)
Para melhor experiência, use um servidor local:

**Python:**
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

**Node.js:**
```bash
npx http-server
```

**VS Code:**
- Use a extensão "Live Server"

Acesse: `http://localhost:8000`
